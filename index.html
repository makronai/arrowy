● Pure Node.js Zero Runtime Dependencies Storage: .arr v1 Relational + Document

Arrowy Database Platform

A standalone, zero-dependency, plug-and-play database engine for Node.js featuring Relational tables and Document collections backed by local disk or GitHub.

$ npm install arrowydb Standalone NPM Package

⚡ Zero Dependencies

Built strictly on native Node.js APIs (crypto, fs, buffer, fetch). Zero bloated node_modules or transitive security risks.

📦 .arr Chunk Storage

Data stored in byte-aware binary chunks with SHA-256 integrity verification, format headers, and optimistic concurrency counters.

🔄 Dual Engine Architecture

Schema-enforced relational tables with query builders alongside MongoDB-compatible document stores with dot-notation querying.

Relational Table Example

import { ArrayDB } from "arrowydb";

const db = new ArrayDB({ provider: "local" });
await db.initialize();

const users = await db.relational("app_db").createTable("users", {
  primaryKey: "id",
  columns: {
    id: { type: "integer", primaryKey: true, autoIncrement: true },
    name: { type: "string", required: true },
    email: { type: "string", required: true, unique: true },
    active: { type: "boolean", default: true }
  }
});

await users.insert([
  { name: "Sarah Chen", email: "sarah@example.com" },
  { name: "Marcus Brody", email: "marcus@example.com" }
]);

const result = await users
  .select(["id", "name", "email"])
  .where("active", "=", true)
  .execute();

console.log(result.data);

Document Collection Example

const products = await db.document("store_db").createCollection("products");

await products.insertOne({
  name: "Apex Keyboard",
  specs: { layout: "ANSI", switches: "Linear" },
  price: 129.99
});

const matches = await products.find({
  "specs.switches": "Linear",
  price: { $lte: 150 }
});

HTTP REST API (Zero Dependencies)

import http from "node:http";
import { createArrayRouter } from "arrowydb/http";

const handler = createArrayRouter(db);
http.createServer(handler).listen(3000);

// Or mount directly into Express:

REST Endpoints

Method Endpoint Description
GET/api/healthProvider connectivity & storage health
GET/api/doctorSystem health and integrity diagnostics
GET/api/databasesList registered databases
POST/api/databasesCreate database ({ name, type })
POST/api/queryExecute relational/document query
POST/api/recordsInsert records into table/collection
GET/api/exportExport dataset (CSV, JSON, JSONL)
